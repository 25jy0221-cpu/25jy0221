# ひびノート

Todo と日記のノート。ビルド不要の静的サイトです(HTML / JS / CSS のみ)。

## ファイル構成

```
index.html              アプリ本体
config.js               「みんなの日記」の接続先設定(Supabase の URL とキーを入れる)
supabase/setup.sql      Supabase に流すSQL(テーブル・合言葉チェック・投稿用の関数)
manifest.webmanifest    ホーム画面に追加するための設定
sw.js                   オフライン対応(Service Worker)
icons/                  アプリアイコン
```

## 公開のしかた

### GitHub Pages
1. GitHub で新しいリポジトリを作る(例: `hibi-note`)
2. このフォルダの中身をすべてリポジトリ直下にアップロード(`index.html` が一番上の階層にあること)
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://ユーザー名.github.io/hibi-note/` で開ける

### Netlify Drop
1. https://app.netlify.com/drop を開く
2. このフォルダごとドラッグ&ドロップする

## ホーム画面に追加

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー(︙)→ 「ホーム画面に追加」または「アプリをインストール」
- **PC (Chrome)**: アドレスバー右端のインストールアイコン

※ iPhone は Safari 以外のブラウザからだと追加できない場合があります。

## 更新するとき

`index.html` を差し替えてアップロードすれば、次にオンラインで開いたときに反映されます。
アイコンなど他のファイルを変えた場合は、`sw.js` の `VERSION` の数字を上げてください。

## データについて

- 日記・Todo は **開いているブラウザの中(localStorage)** に保存されます。サーバーには送られません。
- URL(ドメイン)が変わると、別のサイト扱いになりデータは引き継がれません。
  引っ越すときは、旧サイトで「復元用に書き出す(JSON)」→ 新サイトで「バックアップを読み込む」。
- ホーム画面に追加したアプリと、ブラウザで開いたページは、端末によっては保存領域が別々になります(特に iPhone)。
  どちらか片方に決めて使い、ときどきバックアップを取るのがおすすめです。

## 「みんなの日記」(合言葉で見られる共有タイムライン)のセットアップ

自分用の日記帳・Todo は今までどおり端末の中だけに保存されます(非公開)。
「みんなの日記」は別の機能で、**合言葉を知っている人だけが閲覧・投稿**できます。
ここだけ、データを置くサーバーとして Supabase(無料プランあり)を使います。
画面の名前は変わることがあるので、見つからないときは Supabase の公式ドキュメントも見てください。

### 1. Supabase のプロジェクトを作る
1. https://supabase.com でアカウントを作り、New project を作成(リージョンは Tokyo が近い)
2. データベースのパスワードを決める(控えておく。このアプリでは使いません)

### 2. SQL を実行する
1. `supabase/setup.sql` をテキストエディタで開く
2. **一番下の `'ここに合言葉'` を、自分で決めた合言葉に書き換える**
3. 左メニューの SQL Editor → New query に、ファイルの内容をすべて貼り付けて Run
4. 「Success」と出ればOK

### 3. URL とキーを config.js に貼る
1. ダッシュボード上部の **Connect** ボタン、または Settings → API Keys を開く
2. **Project URL**(`https://xxxx.supabase.co`)と **Publishable key**(`sb_publishable_...`)をコピー
   - Publishable key がなければ、API Keys 画面で「Create new API Keys」を押して作る
   - 昔の `anon` キーでも動きます
3. `config.js` を開いて、2つの値を貼り付ける
4. 変更を GitHub にアップロードし直す

> **secret key / service_role key は絶対に config.js に入れないこと。**
> 公開用キー(publishable / anon)はサイトに載っても、データの読み書きがSQLの関数で制限されているので安全です。

### 4. 使う
サイトを開く → ホームの「みんなの日記」→ 合言葉を入力 → 名前と本文を書いて投稿。
友だちには、サイトのURLと合言葉を伝えてください。

### 仕組みと注意点
- 合言葉はデータベースにハッシュ化して保存されます。直接テーブルを読み書きすることはできず、決められた3つの関数(読む・投稿・削除)だけが公開されています。
- 合言葉をまちがえ続けると(10分間に30回)、いったん全員が入れなくなります。しばらく待てば復活します。
- 投稿は1分間に5件まで。名前20文字・本文1000文字まで。
- 削除できるのは、**その投稿をした端末だけ**です(端末ごとの鍵で判定)。端末を変えたりブラウザのデータを消すと、過去の自分の投稿は自分でも消せなくなります。その場合は Supabase の Table Editor → posts から行を削除できます。
- 名前は自己申告です。合言葉を知っている人は、他人の名前で投稿できてしまいます(なりすまし可能)。
- **合言葉が外に漏れたら、誰でも見られます。** そのときは、SQL Editor で `setup.sql` の一番下の文(合言葉を設定する部分)を新しい合言葉に書き換えて、その文だけを実行してください。
- 無料プランでは、しばらく誰もアクセスしないとプロジェクトが一時停止することがあります。ダッシュボードから再開できます。
- 一度公開した投稿を、全員の画面から確実に消す機能は「投稿した本人による削除」と「管理者(あなた)によるTable Editorでの削除」です。
