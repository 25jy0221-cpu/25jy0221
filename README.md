# ひびノート

Todo と日記のノート。ビルド不要の静的サイトです(HTML / JS / CSS のみ)。

## ファイル構成

```
index.html              アプリ本体(これ1つで動く)
manifest.webmanifest    ホーム画面に追加するための設定
sw.js                   オフライン対応(Service Worker)
icons/                  アプリアイコン
```

## 公開のしかた

### GitHub Pages
1. GitHub で新しいリポジトリを作る(例: `hibi-note`)
2. このフォルダの中身をすべてリポジトリ直下にアップロード(`index.html` が一番上の階層にあること)
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://ユーザー名.github.io/hibi-note/` で開ける

### Netlify Drop
1. https://app.netlify.com/drop を開く
2. このフォルダごとドラッグ&ドロップする

## ホーム画面に追加

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー(︙)→ 「ホーム画面に追加」または「アプリをインストール」
- **PC (Chrome)**: アドレスバー右端のインストールアイコン

※ iPhone は Safari 以外のブラウザからだと追加できない場合があります。

## 更新するとき

`index.html` を差し替えてアップロードすれば、次にオンラインで開いたときに反映されます。
アイコンなど他のファイルを変えた場合は、`sw.js` の `VERSION` の数字を上げてください。

## データについて

- 日記・Todo は **開いているブラウザの中(localStorage)** に保存されます。サーバーには送られません。
- URL(ドメイン)が変わると、別のサイト扱いになりデータは引き継がれません。
  引っ越すときは、旧サイトで「復元用に書き出す(JSON)」→ 新サイトで「バックアップを読み込む」。
- ホーム画面に追加したアプリと、ブラウザで開いたページは、端末によっては保存領域が別々になります(特に iPhone)。
  どちらか片方に決めて使い、ときどきバックアップを取るのがおすすめです。
